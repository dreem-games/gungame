# gungame

Игра от третьего лица с видом сверху на основе LibGDX.

## Запуск проекта
Для запуска проекта из среды разработки требуется запустить класс `DesktopLauncher` в модуле `desktop`.

Для сборки исполняемого файла требуется выполнить одну из следующих команд в зависимости от платформы:

Для windows:
> ./gradlew packageWinX64

Для linux:
> ./gradlew packageLinuxX64

Для mac:
> ./gradlew packageMacAarch64
