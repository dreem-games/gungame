На данный момент референсом является геймпад xbox.

Управление гейпадом:
 - Перемещение: левый стик
 - Прицел: правый стик
 - Выстрел: RB
 - Перезарядка: X
 - Смена оружия: Y
 - Граната: LB
 - Бег: A
 - Рывок: B
 - Выбор оружия: крестовина
 - Выход из игры: кнопка BACK

Управление клавиатурой+мышкой:
 - Перемещение: WASD
 - Выстрел: ЛКМ
 - Перезарядка: R
 - Граната: G
 - Бег: Shift
 - Рывок: пробел
 - Выбор оружия: 1, 2, 3
 - Выход из игры: esc
