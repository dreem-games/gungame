# Управление

Поддерживаются клавиатура с мышью и геймпад.

## Клавиатура + мышь

- **W / A / S / D** — движение
- **Мышь** — прицеливание (герой поворачивается к курсору)
- **ЛКМ** — огонь
- **R** — перезарядка
- **1 / 2 / 3** — смена оружия
- **Колесо мыши** — смена оружия
- **Shift** — бег (тратит стамину)
- **Space** — рывок (тратит стамину)

## Геймпад

- **Левый стик** — движение (при отпущенном стике работает WASD)
- **Правый стик** — прицеливание
- **R2 (правый триггер)** — огонь
- **A** — бег
- **B** — рывок
- **Y** — перезарядка
- **D-pad: влево / вверх / вправо** — смена оружия (1 / 2 / 3)
