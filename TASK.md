# План переноса фичей GunGame (Java -> TypeScript)

Проект перенесён на TypeScript + Phaser 3 + Matter.js. Базовая архитектура создана, но необходимо восстановить весь утраченный геймплей из старой Java-версии.

## ВАЖНО: Разница в физике (Метры vs Пиксели)
В старой Java-версии (Box2D) размеры задавались в метрах (например, герой был радиусом ~0.5м), а отрисовка масштабировалась.
В Phaser 3 + Matter.js физика по умолчанию работает **в пикселях**. Размеры тел (bodies) теперь соответствуют размерам спрайтов на экране (например, радиус героя = 70 пикселей). Для достижения нужного визуального масштаба используется отдаление камеры (`zoom`).

## Задачи для реализации

### 1. Передвижение (Movement)
- [ ] **Бег (Shift)**: Увеличение скорости передвижения при зажатом Shift.
- [ ] **Рывок (Space)**: Резкий дэш в направлении движения или курсора.
- [ ] **Выносливость (Stamina)**: Ограниченный ресурс, который тратится на бег и рывок, и постепенно восстанавливается.

### 2. Оружие и Стрельба (Weapons)
В игре 3 основных типа огнестрельного оружия:
- [ ] **Автомат** (скорострельный, средний урон)
- [ ] **Винтовка** (медленный темп, высокий урон, пробивание)
- [ ] **Дробовик** (выстрел дробью, высокий урон вблизи)
- [ ] **Механика стрельбы**: ЛКМ для выстрела, R для перезарядки, 1/2/3 для смены оружия. Учет патронов и отдачи.
- [ ] **Лазерный целеуказатель**: Всегда включен для активного оружия, рисует луч от дула до точки прицеливания (или препятствия).
- [ ] **Гранаты**: Бросок по клавише G, таймер взрыва. У игрока изначально 2 гранаты.

### 3. Окружение и Эффекты
- [ ] **Взрывы**: Физический импульс во все стороны (откидывает героя и бочки) + анимация из `explosion.atlas`.
- [ ] **Динамическое освещение**: В Java использовался `box2dlights`. Для Phaser 3 нужно реализовать освещение (свет от лазера, дульное пламя, свет от гранат) с помощью `Phaser.GameObjects.Light` или кастомных шейдеров.
- [ ] **Звуки**: Воспроизведение звуков шагов, выстрелов, взрывов.

### 4. Интерфейс (UI)
Создать отдельную UI-сцену (поверх GameScene), которая слушает события через `EventBus`:
- [ ] Полоска здоровья (HealthBar)
- [ ] Полоска выносливости (StaminaBar)
- [ ] Счетчик патронов и текущее оружие
- [ ] Тряска камеры (Camera Shake) при стрельбе и взрывах.

### 5. Мультиплеер / Боты
- [ ] Интеграция второго игрока (`hero2`), который изначально был реализован локально.
- [ ] Настройка сетевого кода (WebSocket/WebRTC) для полноценного онлайна.
